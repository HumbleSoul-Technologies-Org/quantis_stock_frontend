# StockOS - Quick Start (5 Minutes)

## ⚡ Get Running in 5 Steps

### 1️⃣ Start the App
```bash
npm run dev
# Visit: http://localhost:3000
```

### 2️⃣ Login
**Username**: `admin`
**Password**: `admin123`

Click the Admin button or enter manually.

### 3️⃣ Add a Product
1. Click **Products** in sidebar
2. Click **Add Product**
3. Fill form:
   - Name: "Laptop"
   - SKU: "LAP-001"
   - Category: "Electronics"
   - Price: "1200"
4. Click **Add Product**

### 4️⃣ Create a Sale
1. Click **Sales** in sidebar
2. Click **New Sale**
3. Select "Laptop"
4. Enter quantity: "1"
5. Click **Add**, then **Complete Sale**

### 5️⃣ View Dashboard
- Click **Dashboard** to see updated metrics
- Inventory value updated
- Low stock alerts displayed

## 🎯 Common Tasks

### Add a Product
Products → Add Product → Fill form → Save

### Record Stock Movement
Inventory → Record Movement → Select product → Enter quantity → Save

### Create a Sale
Sales → New Sale → Add items → Complete Sale

### View Reports
Reports → Choose type → View data → Export CSV

### Change Currency
Settings → Currency → Select USD/EUR/etc → Save

### Change Password
Settings → Credentials → Enter old & new password → Save

## ❌ Troubleshooting

| Issue | Solution |
|-------|----------|
| Login fails | Use demo account (admin/admin123) |
| Stock didn't update | Refresh page, check sale status |
| Low stock alerts missing | Enable in Settings > Notifications |
| Currency not changing | Settings > Currency > Select > Save |
| Data disappeared | Open browser storage (localStorage) |
