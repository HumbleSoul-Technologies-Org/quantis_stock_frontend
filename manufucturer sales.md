# Modified Sales Structure for Manufacturing Business

This document captures the proposed sales form structure for a manufacturing-oriented business, based on the decision that sales should only record finished goods being sold.

## 1. Core Principle

The sales form should remain focused on selling completed products to customers.

It should not include fields for:

- raw materials
- work in progress (WIP)
- stock stage

It should only include fields that support:

- finished goods sales
- customer transaction recording
- traceability of sold items

---

## 2. Recommended Sales Form Structure

### A. Header / Transaction Details

- Customer name
- Sale date
- Receipt / invoice reference
- Payment type
  - cash
  - credit
  - mobile money
  - other
- Sale type
  - retail
  - wholesale
  - credit sale

### B. Item Entry Section

- Product selection
- Quantity
- Unit price
- Line total
- Add item button

### C. Sale Item Details

Each sale line should support the following optional manufacturing-related fields:

- Product name
- Quantity sold
- Unit price
- Line total
- Batch / lot number
- Production reference
- Packaging / serial number
- Item notes

### D. Summary Section

- Subtotal
- Discount
- Tax
- Grand total
- Payment status
- Submit / save button

---

## 3. Recommended Field Set

### Mandatory fields

- Customer name
- Sale date
- Product
- Quantity
- Unit price
- Total
- Payment type

### Optional fields

- Receipt reference
- Batch / lot number
- Production reference
- Packaging / serial number
- Item notes
- Discount
- Tax

---

## 4. Why This Structure Works

This structure keeps the sales flow simple while still supporting manufacturing businesses that need traceability.

It allows the business to:

- record customer sales normally
- sell only finished goods
- track which batch or lot was sold
- keep production and raw material records separate from sales

---

## 5. Final Recommendation

Use one unified sales form for all business types, but make the manufacturing-related fields optional.

The sales form should be centered around:

- finished goods
- customer transactions
- traceability
- payment handling

It should not try to represent production stages such as raw materials or WIP.
